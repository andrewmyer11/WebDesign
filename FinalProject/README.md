# Site Plan
My site plan for this website was to have a blog about baseball. Where people could come and check up on the latest updates on there favorite MLB teams. There are videos of players hitting homeruns, amazing plays and crazy outfield plays. 

## Home Page

**Goal:** Showcase visual work immediately, establish style, and guide users toward contacting me.

### Structure
- **Navigation:** Logo (left), primary Links to Home, About, and Contact on the right  
- **Hero:** Large full-width image with dark overlay, Centered title text introducing my work/style 
- **Lead-in:** Blockquote: This season has delivered incredible highlights from walk-offs to insane home runs.  
- **Main Content:** Grid-based image gallery; Alternating layouts (2-image and 3-image rows); Hover effects with captions  
- **Supporting Content:** “Featured In” or credibility section (logos or placeholders) 
- **Call-to-Action:** “Work With Me” section, Left: profile image, Right: short message + contact form
- **Footer:** Social media icons, Copyright 

---

## About Page

**Goal:** Introduce yourself and build trust with visitors.

### Structure
- **Navigation:**  Same as Home (consistent across site)
- **Hero / Intro:**  Page title (“About Me”), Short intro paragraph
- **Main Content:**  Personal bio (who you are, what you do), style or approach to photography/design, Possibly a larger profile image
- **Supporting Content (optional):**  Skills, experience, or tools I use
- **Call-to-Action:**  Encourage users to work with me or view my portfolio
- **Footer:**  Same as Home

---

## Contact Page

**Goal:** Make it easy for users to reach me.

### Structure
- **Navigation:**  Same as other pages
- **Hero / Intro:**  Title (“Contact”), Short inviting message
- **Main Content:**  Contact form (name, email, message), email or social links
- **Supporting Content (optional):**  Location or availability info
- **Call-to-Action:**  Reinforce reaching out (e.g., “Let’s work together”)
- **Footer:**  Same as Home
